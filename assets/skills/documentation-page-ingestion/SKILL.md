# documentation-page-ingestion

Prefer a documented version and canonical page. Read the relevant complete sections, including
limitations and examples; exclude nav chrome, cookie/login pages and unrelated generated UI.
Record version/date for unstable APIs. Distinguish a code example from guaranteed behavior.
If JS rendering prevents retrieval, use an available browser integration or mark the gap.
