# wiki-entity-upgrade

Identify missing evidence in a status:skeleton page. Find primary project, author or company
sources. Add identity, actual technical contribution, relevant dates and links. Remove skeleton
status only after filling substantive gaps; a longer description is not sufficient. Do not
use build_x_wiki.py --force or similar options to overwrite an existing rich page.
