# active-crawl-wiki

Read ~/ai-topics/config/hot-topics.yaml and relevant existing pages. Use Codex native web search
for a bounded set of concrete gaps, then read primary sources. Save new raw evidence once and
integrate only novel facts. Report sources checked and gaps remaining. A blocked website is
not permission to fabricate a body or repeat an unlimited fetch loop.
