# dreaming

Check the day's log and current pages before enrichment. Group related articles while retaining
item IDs, URLs, raw paths and decisions. Distinguish already integrated material from a real
new connection. Preserve all decisions in the response and use short theme summaries. For
synthesis read the constituent bodies; enrich existing pages before proposing new concepts.
Archive skip/reference decisions once. If all themes are saturated, report verified no-change
with the checked pages instead of creating another broad concept or rerunning collection.
