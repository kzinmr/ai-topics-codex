# report-quality

Lead with concrete changes or findings. Cite every substantive external claim and link changed
Wiki pages. Separate completed work, no-change decisions and unresolved retrieval. Prefer a
short comparison table for comparable facts. Remove generic filler and unsupported superlatives.
Use actual recorded counts. The runner owns delivery and token accounting; never send messages
from a scheduled job or append fabricated COST_REPORT text.
