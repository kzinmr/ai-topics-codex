# x-article-getxapi-fallback

Use a fallback only when its endpoint and credentials are explicitly configured by the operator.
Inspect available tools rather than inventing a provider API. Compare author, article ID and
body content with the original link. Record which provider supplied the text. Without a usable
fallback, retain the source as reference with an access limitation; do not create a take.
