# wiki-comparison-page-routing

Use comparisons for stable shared criteria and evidence-backed differences across named
alternatives. Put single-product facts on the entity page. Reference a comparison from each
relevant page without duplicating its entire table. Date version-sensitive claims and avoid
invented numeric ratings. Ensure the comparison has a clear user question and sources.
