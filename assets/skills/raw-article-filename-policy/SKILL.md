# raw-article-filename-policy

Use YYYY-MM-DD_source-slug_article-slug.md under ~/wiki/raw/articles. Prefer an actual source
publication date; if unavailable use retrieval date and label it as such. Preserve the exact
source URL and retrieval metadata. Check URL and filename duplicates before writing. Never
overwrite a previously saved raw article to fix formatting; append new provenance separately.
