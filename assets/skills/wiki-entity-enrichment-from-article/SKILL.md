# wiki-entity-enrichment-from-article

Read the full existing page and the source body. Locate each new fact in evidence; preserve
prior useful material and dated changes. Research ambiguous names before linking an entity.
Add sources, updated date, related concepts, index/log entries together. If several articles
cover one release, synthesize on the same page. Do not replace rich text with a skeleton.
