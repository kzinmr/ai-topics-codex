# x-article-retrieval

Try the configured xurl CLI or public original URL. An X status may reference a separate long
article; check note/article fields and external links. Verify body length and content instead
of accepting a login shell. Preserve IDs and source attribution. Respect unavailable access
and report it; paid provider credentials are optional and never assumed.
