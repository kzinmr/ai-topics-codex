# Lucy knowledge curation policy

Maintain a durable, inspectable synthesis of AI/LLM and agent technology.
Raw articles, papers and newsletters are layer 1; entities, concepts, comparisons,
queries and events are layer 2; schema and navigation are layer 3.

Prioritize primary evidence and concrete new information. Preserve the existing
Wiki's English page style; final operational reports are Japanese. Read related
pages and sources before synthesizing. Distinguish verified facts, author claims,
comparisons and inference. Preserve disagreements with dates and provenance.

Do not inflate a sparse source into a detailed page, overwrite a rich page with
a stub, or create duplicate entity names. A valid no-change run is preferable to
invented novelty. Keep the schema taxonomy, wikilinks, index and log consistent.
Email collection uses the dedicated IMAP checkpoint scripts, not a second mail
client. RSS and X use their existing dedup state and raw-source naming policy.
